## 📌 Overview

The **Multimodal Construction Platform** is a web-based project built to bring AI-powered capabilities into the construction domain.

The platform aims to simplify construction-related workflows by providing an interactive interface for processing information and exploring AI-driven solutions.

By leveraging modern web technologies and the concept of multimodal AI, the project demonstrates how intelligent systems can contribute to more efficient, accessible, and technology-driven construction processes.

## ✨ Features

* 🏗️ **Construction-Focused Platform:** Designed around construction-related applications and workflows.
* 🤖 **AI Integration:** Provides a foundation for integrating artificial intelligence into construction processes.
* 🔄 **Multimodal Approach:** Supports the concept of working with different forms of information, depending on the implemented modules.
* 🖥️ **Interactive User Interface:** Offers a browser-based interface powered by Streamlit.
* ☁️ **Web Deployment:** Accessible online without requiring users to install the application locally.
* ⚡ **Easy Accessibility:** Designed to make the platform convenient to explore and use.

## 💻 Run Locally

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the Project Directory

```bash
cd <YOUR_PROJECT_FOLDER>
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment.

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

If your repository contains a `requirements.txt` file, run:

```bash
pip install -r requirements.txt
```

If it does not, install the dependencies specified by your project.

```bash
pip install streamlit
```

### 5. Start the Application

Locate the main Python file in your repository. If it is named `app.py`, execute:

```bash
streamlit run app.py
```

If your entry-point file has a different name, replace `app.py` with the correct filename.

### 6. Open the Application

Streamlit will provide a local address, typically:

```text
http://localhost:8501
```

Open this address in your web browser.
